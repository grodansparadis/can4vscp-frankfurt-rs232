## Path

Set the full path to the driver file **vscpl1_can4vscpdrv.dll/so**

## Device Configuration String

The serial channel. Typically **COM1/COM2/COM3** on windows and
**/dev/ttyS0** **/dev/ttyUSB0** etc on Unix.
